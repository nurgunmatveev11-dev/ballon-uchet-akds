# Баллон.учёт для Android

Это устанавливаемая Android оболочка для опубликованного приложения. Экран загружается с GitHub Pages, а данные и роли — из Supabase. Для работы нужен интернет. Аккаунт ChatGPT не используется.

Встроенный браузер открывает только страницу приложения. Сторонние ссылки передаются системному браузеру. Для сертификатов и разрешений используется системный выбор файлов. Протокол Word, скачанные документы и PDF сохраняются или печатаются через системные окна Android.

Демо сборка подписана отладочным ключом GitHub Actions. При следующей сборке ключ может измениться: тогда для обновления понадобится удалить старую версию. Данные учёта находятся в Supabase и не удаляются вместе с APK. Для стабильных обновлений нужна отдельная постоянная подпись релизной сборки.

Приложение открывает `https://nurgunmatveev11-dev.github.io/ballon-uchet-akds/`. Если этот адрес изменится, обновите `APP_URL`, `APP_HOST` и `APP_PATH` в `MainActivity.java` и соберите APK заново.
