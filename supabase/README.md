# Supabase: регистрация и сотрудники

`registration-and-staff.sql` применяется к действующему проекту после исходной схемы,
`four-roles.sql` и `audit-and-documents.sql`. Скрипт уже применён к проекту
`actfujjqcvkfwuiutcyx` 18 ноября 2026 года. Повторно запускать его для этого проекта не нужно.

Никогда не размещайте `service_role` key в браузерном приложении. Он обходит RLS и должен использоваться только в защищённом серверном коде.

## Сопоставление ролей

| Код | Роль |
|---|---|
| `warehouseman` | Кладовщик |
| `operator` | Оператор |
| `akds_head` | Начальник АКДС |
| `skk_head` | Начальник СКК |
| `observer` | Устаревшая роль; миграция переводит её в `operator` |

## Регистрация по электронной почте

В действующем проекте подтверждение почты включено, а Site URL настроен на веб-приложение.
На тарифе Free без своего SMTP письмо содержит ссылку подтверждения. Для ввода кода
настройте собственный SMTP или другое средство отправки и замените шаблон
**Confirm sign up** на письмо с `{{ .Token }}`. После этого установите
`emailCodeEnabled: true` в `cloud-config.js`.
Новые аккаунты получают неактивный профиль: выбранная при регистрации роль сохраняется как заявка, а доступ включает начальник АКДС после подтверждения почты.
Отключение аккаунта закрывает доступ и сохраняет историю операций.
